# Sesión 1B Roles departamentos y políticas

## Entregable

Roles ADMIN, KNOWLEDGE_MANAGER, EMPLOYEE y AUDITOR con asignaciones únicas. Departamentos con
código normalizado y memberships únicas. Políticas puras centralizan actor, acción y alcance;
los servicios aplican esas decisiones antes de exponer o modificar recursos.

Endpoints administrativos permiten gestionar usuarios/roles, departamentos y memberships con
validación y paginación. `/me` devuelve roles, departamentos activos y capabilities vigentes.
Desactivar revoca sesiones y el último ADMIN activo no puede retirarse o desactivarse. El seed
demo materializa las personas/departamentos del corpus y sincroniza sus permisos explícitamente.

## Evidencia

El 15 de octubre de 2026:

- Ruff y mypy estricto: PASS, 50 archivos comprobados por tipos.
- Migración `0003` aplicada y `alembic check` sin drift.
- Suite completa con `DOCUMIND_TEST_INFRA=1 uv run pytest`: **69 PASS**, sin omisiones.
- Matriz pura: 18 pruebas de políticas, incluyendo todas las combinaciones de rol/capability.
- Siete pruebas API de organización, con negativos parametrizados para KM/EMPLOYEE/AUDITOR,
  paginación, duplicados, IDs ajenos, privilegios, último admin y desactivación.
- Quitar una membership cambia departamentos y decisión READ con el mismo access token.
  Asignar y retirar ADMIN cambia el acceso a `/admin/users` sin volver a iniciar sesión.

Las pruebas API usan esquemas temporales transaccionales de PostgreSQL. El rollback incluye
DDL y datos, por lo que no modifican cuentas o permisos demo existentes. Las migraciones y el
drift se prueban aparte contra el esquema real, desde una base vacía en CI.

## Nombre y corpus

Por decisión del usuario, el producto se llama **Documint**, sin sufijo AI/IA. Se actualizaron
interfaz, título de API, documentación y archivos sintéticos. Corpus/dataset 1.1 conservan
hechos y preguntas; sus hashes identifican los archivos con la nueva marca. Se renderizaron y
revisaron las cuatro páginas PDF/Word otra vez. Se conservan IDs técnicos y credenciales demo.
