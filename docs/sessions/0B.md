# Sesión 0B Servicios locales y persistencia

## Entregable

Compose con PostgreSQL 17/pgvector, Redis y MinIO compilado desde código oficial fijado.
Puertos en loopback, volúmenes separados, configuración compartida mediante Pydantic Settings,
migración Alembic `0001` e interfaz de almacenamiento S3. `/health` conserva liveness y
`/ready` exige esquema vigente, pgvector, Redis y bucket privado accesible.

## Evidencia local

Ejecutado el 15 de octubre de 2026 con Docker Engine 29.8.1 y Compose 5.5.1:

- `docker compose up -d --build --wait --wait-timeout 120`: los tres servicios healthy.
- `uv run alembic upgrade head`: migración sobre una base vacía; segunda ejecución correcta.
- `uv run python -m scripts.init_storage`: bucket privado inicializado.
- `DOCUMIND_TEST_INFRA=1 uv run pytest -m infrastructure`: **7 pruebas aprobadas**.

La suite real verifica distancia pgvector, escritura/lectura/borrado binario S3, readiness
con todos los servicios, fallos de conexión individuales y ejecución de Celery con Redis.
Las pruebas de fallo utilizan un puerto cerrado para un cliente aislado; no detienen otros
servicios. La suite sin infraestructura usa probes sustituidas solo para contratos HTTP y
un worker con transporte en memoria, claramente identificados.

CI añade un job separado que levanta los servicios desde cero, migra dos veces, inicializa
storage y ejecuta esta suite. La confirmación remota se registra después del push.

## Decisiones y límites

PostgreSQL del host ya ocupaba 5432. Los puertos propios evitan interferir con él y otros
contenedores. Las credenciales incluidas son exclusivamente de desarrollo y no hay archivos
privados ni claves de IA. El estado de los servicios no implica que exista procesamiento RAG.

MinIO comunitario está archivado: se conserva el stack mediante su código fuente final,
con limitación de mantenimiento registrada en `infra/README.md`. Las imágenes de la aplicación,
TLS y configuración de producción se implementan en fase 8. No se ejecutan migraciones ni se
crean buckets como efecto de una consulta GET.
